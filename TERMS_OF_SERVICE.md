## 2. Service Description

AI DocuSearch is an AI-powered document search application that:
- Accepts document uploads (PDF, DOCX, TXT)
- Extracts text using OCR when necessary
- Processes user queries using AI models
- Returns AI-generated answers based on document content
- Maintains conversation history and feedback

The Service operates in **Hybrid Mode only**:
- Attempts RAG (Retrieval-Augmented Generation) first
- Falls back to Direct LLM if RAG is unavailable
- This ensures reliability across different device/resource scenarios
